# Multi-Agent System (MAS4FLP)

## 1. Overview

This program implements a Multi-Agent System (MAS) for multi-objective facility location optimization using Binary, Proportional, and Pareto-Huff behavior models.

The system consists of a Base Agent (A0) that coordinates the optimization process and three behavior agents:

- **A1 — Binary Agent:** Generates proposals using learned Binary probabilities.
- **A2 — Proportional Agent:** Generates proposals using learned Proportional probabilities.
- **A3 — Pareto-Huff Agent:** Generates proposals using learned Pareto-Huff probabilities.

The program supports both two-behavior (2BM) and three-behavior (3BM) configurations and runs sequentially using Python.

## 2. Requirements and Execution

**Requirements:** Python 3 and NumPy.

Install NumPy if needed:

```bash
pip install numpy
```

The required candidate-selection probabilities must first be generated using the `agent_learning` program.

Run MAS from the **repository root directory**:

```bash
python -m mas.main
```

## 3. Configuration

Experiment settings are defined in `mas/settings.py`.

| Setting | Description |
|---|---|
| `BEHAVIOR_MODELS` | Select 2BM or 3BM |
| `K_VALUES` | Number of facilities to select |
| `TEST_CASES` | Test cases to execute |
| `PROBABILITY_SEED` | Select previously learned probability files |
| `SEEDS` | Independent MAS search seeds |
| `MAX_ITERS` | Number of MAS iterations |
| `DUPLICATE_LIMIT` | Local duplicate threshold before uniform fallback |
| `PARETO_EPSILON` | Epsilon value for Pareto archiving |
| `VERBOSE` | Display execution progress |

Example configuration:

```python
BEHAVIOR_MODELS = ["binary", "proportional"]

K_VALUES = [3]
TEST_CASES = ["TC1"]

PROBABILITY_SEED = 110
SEEDS = [95]

MAX_ITERS = 3000
DUPLICATE_LIMIT = 50
PARETO_EPSILON = 1e-6

VERBOSE = False
```

For 3BM, include `"pareto_huff"` in `BEHAVIOR_MODELS`.

Multiple test cases, facility counts, and MAS seeds can be selected.

## 4. MAS Procedure

The Base Agent requests facility-location proposals from the active behavior agents. Each agent generates proposals using its learned selection probabilities and checks its local proposal history.

The Base Agent checks global duplicates and requests replacements when necessary. After the configured number of consecutive local duplicates, agents switch to uniform sampling.

Each globally unique proposal is evaluated by all active behavior agents using their corresponding objective functions. The Base Agent collects the utilities and updates the epsilon-Pareto archive.

The process continues until the configured number of iterations is completed.

## 5. Agent Communication

MAS4FLP uses a custom FIPA-ACL-style interaction protocol named `mas4flp-custom`.

Communication uses three performatives: `REQUEST`, `PROPOSE`, and `INFORM`, supporting proposal requests, evaluation requests, responses, and termination notifications.

Messages are exchanged through in-process Python method calls. The implementation does not use network communication or claim compliance with the standard FIPA Request or Contract Net interaction protocols.

## 6. Output Files

Results are saved under `outputs/mas/`.

Example:

```text
outputs/mas/2BM/k3/prob_seed_110/
    limit_50/eps_1e-06/iters_3000/TC1/seed_95/
```

| File | Description |
|---|---|
| `summary.csv` | Experiment settings, evaluation counts, duplicates, message counts, and runtime |
| `mas_archive.csv` | Final epsilon-Pareto archive |
| `strict_front.csv` | Strict non-dominated solutions among evaluated solutions |
| `evaluated_solutions.csv` | All globally unique evaluated solutions and objective values |
| `agent_statistics.csv` | Agent-specific proposal, duplicate, fallback, and evaluation statistics |

The shared `summary.csv` is located at `outputs/mas/summary.csv`. Other files are stored separately for each experiment.

## 7. Evaluation and Reproducibility

- Each accepted proposal is evaluated using all active behavior objectives.
- For 2BM with 3,000 completed iterations, the MAS evaluates 6,000 unique solutions, corresponding to 12,000 scalar objective evaluations.
- Offline Agent Learning costs are recorded separately in `outputs/agent_learning/summary.csv` and should be included in total computational-budget comparisons.
- MAS search seeds are independent of the seed used to generate learned probabilities.
- Execution time includes proposal generation, duplicate handling, objective evaluations, Pareto archiving, and simulated message exchanges. Data loading and output writing are excluded.
- The strict sampled front can be compared with the exact reference fronts generated by `complete_enumeration` to evaluate Pareto-front recovery.
- The strict sampled front contains only non-dominated evaluated solutions and is not necessarily the globally exact Pareto front.
