Objektų vietų parinkimo uždavinys

Tarkime, kad duotoje geografinėje teritorijoje veikia kelios paslaugas gyventojams teikiančios įmonės, sumoje turinčios NPF objektų (angl. Preexisting Facilities). Į rinką nori įeiti nauja įmonė, kuri planuoja atidaryti NX naujų objektų. Reikia parinkti miestus, kuriuose atidaryti nauji objektai pritrauktų kuo daugiau klientų.

Objektus klientai renkasi pagal geografinį atstumą − visi vieno miesto gyventojai renkasi artimiausią objektą. Atstumas tarp dviejų geografinių taškų skaičiuojamas pagal Haversino formulę, kurios realizaciją C++ kalboje rasite virtualioje mokymosi aplinkoje.

Vertinant naujų objektų naudingumą, kiekvienam miestui yra taikomas toks algoritmas:

  1. randamas artimiausias objektas iš jau rinkoje esančių objektų;
  2. randamas artimiausias objektas iš planuojamų naujų objektų;
  3. jei atstumas iki artimiausios naujo objekto yra mažesnis už atstumą iki artimiausio jau rinkoje esančio objekto, tai prie naujos įmonės naudingumo pridedama visa miesto perkamoji galia (visi klientai);
  4. jei atstumas iki artimiausios naujo objekto yra lygus atstumui iki artimiausio jau rinkoje esančio objekto, tai naujai įmonei atitenka trečdalis miesto perkamosios galios (pavyzdžiui, jei mieste yra 1000 gyventojų, tai prie naujos įmonės naudingumo pridedama 333.333333 klientų perkamoji galia).

Rinkoje jau esantys NPF objektai išdėstyti didžiausiuose miestuose, po vieną viename mieste. Nauji objektai gali būti statomi bet kuriame mieste, įskaitant ir tuos, kuriame jau yra konkurentų objektas, tačiau viename mieste gali būti tik vienas naujas objektas.

Laboratorinio darbo #1 užduotis

Duotas duomenų failas data.dat, kuriame aprašyti 50 Lietuvos gyvenviečių duomenys: geografinės koordinatės (platuma ir ilguma) ir populiacijos. Taip pat duotas programos šablonas, kuriame yra:

  • globalūs kintamieji;
  • funkcijų, kurias reiks įgyvendinti, prototipai;
  • pagrindinės funkcijos main pavyzdys.

Įgyvendinkite šias funkcijas:

  • void readFile(), kuri nuskaito duomenis iš failo data.dat, taškų koordinates išsaugant dvimačiame masyve coord, o populiacijas − vienmačiame masyve pop;
  • printData(), kuri atspausdina visus duomenis: taškų koordinates ir populiacijas (vienoje eilutėje − vieno taško duomenys)
  • void printData(int n), kuri atspausdina n taškų duomenis (vienoje eilutėje − vieno taško duomenys)
  • double HaversineDistance(int i, int j), kuri paskaičiuoja ir grąžina atstumą kilometrais tarp dviejų geografinių taškų, kurių indeksai masyve coord yra funkcijos parametrai i ir j;
  • double getClosestDistance(int i, int* F, int numF), paskaičiuoja ir grąžina atstumas nuo geografinio taško, kurio indeksas yra i, iki artimiausio objekto aibėje F, kurioje yra numF objektu indeksai.
  • double getUtilityOfX(int* X, int numX), kuri paskaičiuoja ir grąžina perkamąją galią tenkančią visiems naujiems objektams aibėje X, kurioje yra numX objektų indeksai.

Testavimo atvejai:

  • P = {0, 1, 2, 3, 4}, X = {5, 6, 7}. Rezultatas: 15.7809.
  • P = {0, 1, 2, 3, 4}, X = {8, 9, 10}. Rezultatas: 11.5232.
  • P = {0, 1, 2, 3, 4}, X = {0, 1, 2}. Rezultatas: 25.1449.
