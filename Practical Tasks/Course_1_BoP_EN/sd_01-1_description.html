Facility Location Problem

Suppose several companies providing services to residents operate in a given geographical area and together have NPF existing facilities (Preexisting Facilities). A new company wants to enter the market and plans to open NX new facilities. The task is to choose the cities where the new facilities would attract the largest number of customers.

Customers choose facilities based on geographical distance: all residents of a city choose the nearest facility. The distance between two geographical points is calculated using the Haversine formula, whose C++ implementation is available in the virtual learning environment.

To evaluate the utility of the new facilities, the following algorithm is applied to each city:

  1. find the nearest facility among the facilities already operating in the market;
  2. find the nearest facility among the planned new facilities;
  3. if the distance to the nearest new facility is less than the distance to the nearest existing facility, add the entire purchasing power of the city (all customers) to the new company's utility;
  4. if the distance to the nearest new facility equals the distance to the nearest existing facility, the new company receives one-third of the city's purchasing power (for example, if a city has 1000 residents, the purchasing power of 333.333333 customers is added to the new company's utility).

The NPF existing facilities are located in the largest cities, with one facility per city. New facilities may be built in any city, including cities where a competitor already has a facility. However, each city may have only one new facility.

Laboratory Work #1 Task

You are given a data file data.dat containing data for 50 settlements in Lithuania: geographical coordinates (latitude and longitude) and populations. You are also given a program template containing:

  • global variables;
  • prototypes of the functions you need to implement;
  • an example of the main function.

Implement the following functions:

  • void readFile(), which reads data from the file data.dat, stores the point coordinates in the two-dimensional array coord and the populations − in the one-dimensional array pop;
  • printData(), which prints all data: the coordinates and population of each point (one point per line);
  • void printData(int n), which prints the data for n points (one point per line);
  • double HaversineDistance(int i, int j), which calculates and returns the distance in kilometres between two geographical points whose indices in the coord array are given by the function parameters i and j;
  • double getClosestDistance(int i, int* F, int numF), which calculates and returns the distance from the geographical point with index i to the nearest facility in the set F, which contains numF facility indices;
  • double getUtilityOfX(int* X, int numX), which calculates and returns the total purchasing power received by all new facilities in the set X, which contains numX facility indices.

Test cases:

  • P = {0, 1, 2, 3, 4}, X = {5, 6, 7}. Result: 15.7809.
  • P = {0, 1, 2, 3, 4}, X = {8, 9, 10}. Result: 11.5232.
  • P = {0, 1, 2, 3, 4}, X = {0, 1, 2}. Result: 25.1449.
