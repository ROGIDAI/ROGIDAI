Facility Location Problem

Suppose several companies providing services to residents operate in a given geographical area, with a total of N PF facilities ( Preexisting Facilities ). A new company wants to enter the market and plans to open N X new facilities. The task is to select the cities in which the new facilities would attract the largest number of customers.

Customers choose facilities according to geographical distance: all residents of a city choose the nearest facility. The distance between two geographical points is calculated using the Haversine formula , for which a C++ implementation is provided in the virtual learning environment.

When evaluating the utility of the new facilities, the following algorithm is applied to each city:

  1. Find the nearest facility among those already operating in the market.
  2. Find the nearest facility among the planned new facilities.
  3. If the distance to the nearest new facility is smaller than the distance to the nearest existing facility, add the city's entire purchasing power (all customers) to the utility of the new company.
  4. If the distance to the nearest new facility equals the distance to the nearest existing facility, the new company receives one third of the city's purchasing power. For example, if a city has 1,000 residents, purchasing power equivalent to 333.333333 customers is added to the utility of the new company.

The N PF facilities already operating in the market are located in the largest cities, one facility per city. New facilities may be established in any city, including a city where a competitor already has a facility; however, only one new facility may be established in any given city.

Laboratory Work No. 1 — Assignment

A data file named data.dat is provided, containing data on 50 Lithuanian settlements: geographical coordinates (latitude and longitude) and populations. A program template is also provided, containing:

  • Global variables.
  • Prototypes of the functions to be implemented.
  • An example of the main function, main .

Implement the following functions:

  • void readFile() — reads data from data.dat , storing point coordinates in the two-dimensional array coord and populations in the one-dimensional array pop .
  • printData() — prints all data: point coordinates and populations, with the data for one point on each line.
  • void printData(int n) — prints data for n points, with the data for one point on each line.
  • double HaversineDistance(int i, int j) — calculates and returns the distance in kilometres between two geographical points whose indices in the coord array are the function parameters i and j .
  • double getClosestDistance(int i, int* F, int numF) — calculates and returns the distance from the geographical point with index i to the nearest facility in set F , which contains numF facility indices.
  • double getUtilityOfX(int* X, int numX) — calculates and returns the purchasing power attributable to all new facilities in set X , which contains numX facility indices.

Test cases:

  • P = {0, 1, 2, 3, 4}, X = {5, 6, 7}. Result: 15.7809 .
  • P = {0, 1, 2, 3, 4}, X = {8, 9, 10}. Result: 11.5232 .
  • P = {0, 1, 2, 3, 4}, X = {0, 1, 2}. Result: 25.1449 .
